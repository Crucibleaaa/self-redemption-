# 逻辑不完备实验设计

*Design of Logical Incompleteness Experiments*

王语辰 (Wang, Yuchen) | 独立研究者 | 2026-08-15

## 问题

逻辑完备性定理 (任意阶/元/主客体): 解耦 D = R1 排除 + R2 对消 +
R3 分层 作用后完备 (完美 OOD)。**不完备的条件是什么?** 完备性的
反例/边界 — 逻辑不完备实验: 每个解耦缺失时, 训练不完备 (OOD 崩)
的实证。

## 不完备条件清单 (对照解耦三算子)

| 缺失 | 不完备形态 | 已有证据 |
|---|---|---|
| 无 D (未解耦) | 直觉路径: 跨表示全崩 | I7n (0/32) |
| 无 R1 (排除缺失) | 自指混入 (主体 ∈ 自身作用域) | 待测 |
| 无 R2 (对消缺失) | 方向未对消 (主客混合) | 待测 |
| 无 R3 (分层缺失) | 阶混合 (无层函数, Z/101 反例) | 待测 |
| 单组对称性 | 方向不可定义 (I3/I7w: 单轴无方向) | I3/I7w |
| 跨锚零样本 | 锚绑定 (运算不迁移) | I7k (0/32) |
| 跨锚单声明 | 不稳定 (4/5) | I7t |
| 单表示训练 | 跨表示崩 (直觉完备 ≠ 结构完备) | I7n/I7o |

## 判据

不完备 = 训练 OOD 失败 (样本全对 < 100%) 或跨表示剥离崩。
完备的判定 = 解耦后跨表示稳定 (结构路径存在)。

## 实验设计

### E-A: 无 R3 (分层缺失) — 阶不完备

训练数字表示深度混合 (链长 1..9 无分层序), OOD 深度外推 —
不完备预测: 无层函数时高阶 (深迭代) 崩 (Z/101 反例对应)。

### E-B: 无 R1 (排除缺失) — 元不完备

训练含自指样本 (运算 x 作用于自身作用域 x∈scope(x)), OOD 干净
样本 — 不完备预测: 自指未排除 → 歧义 → OOD 崩。

### E-C: 无 R2 (对消缺失) — 主客体不完备

方向样本未对消 (主动/被动混合, 无 (a-b)+(b-a)=0 配对), OOD
方向判定 — 不完备预测: 方向二义 → 崩。

### E-D: 跨表示不完备 (对照)

单表示训练 → 跨表示 OOD (I7n 已证 0/32) — 直觉完备 ≠ 结构完备。

## 结论 (2026-08-15 实验修正)

不完备**未出现**于解耦算子缺失 (表示内训练 — E-A 10/10, E-B 8/8):
直觉路径吸收一切 (表示内统计可学, 自指/混合深度不影响表示内 OOD)。
不完备的真实形态 (已有证据):
1. **结构不完备**: 跨表示剥离崩 (I7n 0/32 — 直觉完备 ≠ 结构完备)
2. **定义不完备**: 单维度方向结构性不可定义 (I3/I7w)
3. **锚不完备**: 跨锚零样本崩 (I7k 0/32), 单声明不稳定 (I7t 4/5)

修正: 不完备不是"解耦算子缺失"的训练现象 (直觉吸收), 而是
**剥离/维度/锚**三个层面的结构现象。完备性判据 (解耦后跨表示
稳定) 只在剥离时检验 — 表示内 1.000 无法区分完备与不完备
(I7n 纪律)。
