# 最少对称性组数分析: 方向声明的组数下界

日期: 2026-08-15 | 承接 I7u (轴是正交对称轴上的相位) / I7v (两组对称性定位方向)

## 问题

如果声明的方向**不是**两组正交轴, 需要至少几组对称性可以声明方向?
(用户怀疑 3 或 4 组 — 只要正交对称有相位, 就意味着角度有映射)

## 理论分析 (群论框架)

### 1. 方向 = 球面点, 对称性 = 反射生成

- 有向方向 = 单位向量 ∈ S^{n-1} (n 维球面): 2 维方向 1 参数 (θ),
  3 维方向 2 参数 (θ, φ), k 维方向 k−1 参数
- 正交变换 = 等距 = 对称性; Cartan-Dieudonné: n 维正交群 O(n)
  由 ≤ n 个反射生成; 旋转 = 2 个反射复合 (保向)
- 定位方向 = 确定球面点的坐标 → 需要表示方向的自由度

### 2. 每组对称性提供的自由度

| 组数 | 结构 | 方向自由度 | 可定位方向 |
|---|---|---|---|
| 1 | 单反射 (±) | 0 连续 (二值) | 仅二值 (±) — 不可定位方向 (I3/I7w) |
| 2 | 双反射复合 = 旋转 | 1 (角度 θ) | 平面方向 (I7w: 16/16 实证) |
| 3 | 三反射 (3D 一般正交) | 2 (θ, φ) | 球面方向 |
| 4 | 四反射 (4D/双复) | 3 | 更高维方向 |

### 3. 用户怀疑 3-4 组的理由

"正交对称有相位 ⟹ 角度有映射": 相位 (I7u) 是连续量 (角度),
角度映射到结构需要:

- **非正交声明 (一般位置)**: 两组非正交轴的方向定位 — 斜坐标
  基仍 2 自由度, 但声明 (轴间关系) 的确定需要第 3 组 (消歧:
  两个轴的关系不足以确定第三方向?)
- **相位 → 角度映射的解析**: 角度有映射 (相位到角度), 映射的
  确定 (锚定/刻度) 可能需要额外对称组 (3 组: 方向 + 刻度?
  4 组: 方向 + 刻度 + 手性?)

### 4. 实验设计 (组数扫描)

- 任务: 方向定位 (k 轴相位 → 方向判定), 轴数 k ∈ {1, 2, 3, 4}
- 每组: k 个 succ 概念 (同锚), 方向 = k 相位向量
- 判据: 最少 k 使方向定位 OOD 稳定 (训练外相位全对)
- 理论预测: k=2 正交可定位 (I7w); 非正交/多参数方向 k≥3;
  饱和点 = 最少声明组数

## 结论 (待实验)

方向声明的最少组数: 正交双轴 = 2 (实证); 一般位置/角度映射
= 3 或 4 (待测, 用户怀疑). 分析框架: 自由度 (球面维数) +
反射生成 (Cartan-Dieudonné) + 相位-角度映射的锚定需求.
