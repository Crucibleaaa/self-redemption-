# 逻辑完备实验设计方法论

*Methodology of Logical Completeness Experiments*

王语辰 (Wang, Yuchen) | 独立研究者 | 2026-08-15

## 摘要

逻辑完备性定理 (任意阶任意元任意主客体) 以"完美 OOD (判定 1.000 /
0 残差)"为判定。本文回顾 E1-E13 实证过程, 提出**逻辑完备实验方法论**:
完备性的实验验证必须满足三条升级纪律 — (i) token 级报告 (聚合 acc
掩盖崩点), (ii) 跨表示剥离 (直觉完备 ≠ 结构完备), (iii) 声明/差异题
设计 (训练信息指向准确结构)。核心判据: **逻辑完备 = 解耦后跨表示
稳定** (结构路径存在的判据)。实验证据显示: 未解耦表示跨表示全崩
(直觉路径); 轴间声明可桥接 (同锚稳定, 跨锚需冗余双声明); 正交声明
与等价声明同等桥接能力 — 支持推论: 正交本身是对称性, 不存在一根轴
与任意轴正交, 而是正交对称轴上的相位。

## 1. 背景: 逻辑完备性定理及其判定问题

逻辑完备性定理 (2026-08-14): 解耦算子 D = Lift∘Exclude (R1 排除
+ R2 对消 + R3 分层) 作用于全部自指点后, 任意阶 (n 阶谓词)、任意
元 (k 元谓词)、任意主客体配置 (主动/被动) 逻辑结构完备 — 模型训练
达到完美 OOD (判定 1.000 / 0 残差), 无歧义。

该定理的工程验证 (2026-08-14): 任意阶 (deepiter 深度 1-5 → 1.000),
任意元 (二元分数除法 → 1.000), 主客体 (symop → 1.000), 解耦后
完备 (原生二元迭代 → 结构 1.000)。代数验证: R1 a-a=0, R2
(a-b)+(b-a)=0 全局成立; R3 分层非天然结合 (Z/101 反例, 需构造性升层)。

**问题**: 2026-08-15 的实证 (E1-E13) 揭示 — "OOD 1.000" 本身有歧义:
所有 OOD 1.0 可能只是**直觉路径** (表示内统计外推), 不是**结构路径**
(跨表示不变的规则)。跨表示剥离实验 (I7n): 训练应用链表示, OOD 同一
数值换表示 (迭代表达/位置-值记法) — 全崩 (0/32)。因此完备性定理的
"完美 OOD" 判定需要升级。

## 2. 方法论: 逻辑完备实验三纪律

### 2.1 token 级报告 (聚合 acc 掩盖崩点)

实证必须报告: 样本全对数 + token 对/总数 + 每位置正确率 (崩点定位)。
聚合 acc (0.99/1.0) 掩盖"哪里崩" — token 级暴露直觉路径的失效位置。
例: 跨表示剥离崩在表示差异的第一个 token (位置 3: 0/32), 输入头
(is_true/bracket/op) 仍 32/32; 跨锚崩在结果尾部 (会读不会算);
位置-值记法大面积崩 (0.23)。崩点形态 = 机制指纹。

### 2.2 跨表示剥离 (直觉完备 ≠ 结构完备)

完备性的结构判据: **解耦 (D) 后跨表示不崩**。同一数值用不同表示
(应用链 / 迭代表达 / 位置-值记法) 的判定 — 直觉路径 (表示内统计)
崩, 结构路径 (数值不变量) 过。实证: 未解耦时跨表示全崩 (I7n);
多表示联合训练不诱导跨表示不变量 (I7o) — 结构路径在当前训练设置下
不可直接教得, 必须经声明。

### 2.3 声明/差异题设计 (训练信息指向准确结构)

- **对错题**: 结构错题 (锚定错: 锚基点链 ≠ 锚 value_zero 链 = 假),
  让锚定语义成为训练信息
- **对比题 (声明)**: 轴间关系声明 (等价: succ_a 链 = succ_b 链;
  正交: orthogonal(succ_a 链, succ_b 链)) — 桥接工具: 同锚声明
  单独使 OOD 0/32 → 32/32 (I7q); 跨锚需冗余双声明稳定 (I7t)
- **差异题 (混淆对)**: 2×2 vs 2+2 (结果同), 0×2 vs 0+2 (形式似
  结果不同) — 运算区分外推 (56/56)

## 3. 单轴完成性: 锚绑定与声明冗余

单轴训练能否覆盖多轴 (正交=对称性猜想):
- 单轴零样本: 0/32 (不完成 — 轴间零共享, E10)
- 单轴 + 同锚声明: 3/3 稳定完成 (E12/I7q)
- 单轴 + 跨锚单声明: 4/5 不稳定 (seed 敏感)
- 单轴 + 跨锚双声明 (正交+等价): 5/5 稳定完成 (I7t)

结论: 运算是**锚绑定**的 (锚是结构身份, succ 是同锚下可翻译记法);
单轴完成性依赖声明的锚类型与冗余度。锚类型 (value_zero/basepoint)
对训练无差异 (I7j/I7l)。

## 4. 推论: 正交是对称性 — 轴是正交对称轴上的相位

若正交本身是对称性 (正交变换 = 等距 = 对称操作, O(n) 群), 则:

1. **不存在一根轴与任意轴正交** — 正交是成对的轴间对称关系, 由
   对称变换生成; 不存在"绝对正交轴" (对所有轴正交的轴)
2. **每条轴是正交对称轴上的相位** — 轴的方向 = 对称群作用下的
   相位位置 (如旋转角度); 轴间关系 (正交/等价) 是相位关系

实证支持 (I7t): 正交声明与等价声明同等桥接能力 — 轴间关系声明
不区分"正交"与"等价"的语义, 都提供相位关系的桥接; 双声明 (冗余
相位关系) 稳定化跨锚桥接。各轴对比 = 相位对比 (对称变换下的位置),
非独立实体对比。

## 5. 结论

逻辑完备实验方法论: token 级报告 + 跨表示剥离 + 声明/差异题设计。
完备性的结构判据 = 解耦后跨表示稳定。推论: 正交 = 对称性 ⟹ 轴是
正交对称轴上的相位, 不存在绝对正交轴。
