# EXP-BASE-OP: 超出 1 的基点算符 — 恢复方法分析

日期: 2026-08-14 | run_exp 配置驱动 (base_op kind)

## 设计

基点 b (>1) 算符: f(x) = b·x - b·(b-1) (固定点 = b)
- b=2: f(x)=2x-2, f(2)=2; b=3: f(x)=3x-6, f(3)=3
恢复方法:
- none: f(x) 原样 (基线)
- vec: 向量收缩 — 0 基点坐标 y=x-b, 表达 = 纯缩放 g(y)=b·y
- iter: 结构迭代 — f(f(x)) 沿定义链两步

## 结果

| 配置 | 判定口径 | epoch 末 |
|---|---|---|
| base2_none | 0.997 | 0.98 |
| base2_vec | 0.997 | 0.98 |
| base2_iter | 0.997 | 0.98 |
| base3_none | 0.997 | 0.98 |
| **base3_vec** | **1.000** | 1.00 |
| base3_iter | 0.997 | 0.98 |

(初始版 vec 实现偏差, 修正为 0 基点纯缩放后重测)

## 结论

1. **简单向量收缩 (0 基点纯缩放 b·y) 有恢复倾向**: base3_vec 1.000
   (恢复), base2_vec 0.997 (接近) — 但与基线差小 (0.6%), 需多种子确认
2. **结构迭代 (iter) 不恢复**: 0.997 与基线相同 — 沿结构迭代收缩
   不是恢复方法 (f(f(x)) 表达不改善)
3. **恒等式支撑**: 基点 b 算符的 0 基点表达 = 纯缩放 b·y
   (f(y+b)-b = b·y, heap_verify 验证 2x-2=2(x-1), 3x-6=3(x-2) 成立)

## 待确认

- base2_vec 0.997 vs base3_vec 1.000: 需多种子重复 (样本小, 差异可能
  是种子/样本波动)
- 若多种子下 vec 普遍 ≥0.998 ⟹ 简单向量收缩是恢复方法;
  否则需沿结构迭代 (更复杂恢复)
