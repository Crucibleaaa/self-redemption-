# EXP-NEG-AUX-INCR: fold_num_v5 基线上的 neg 辅助 token 增量实验 — 结果记录

日期: 2026-08-14 | 基线 = fold_num_v5 (OOD 泛化最好: acc 0.9938, 8 epochs)

## 设计

在 fold_num_v5 配置 (58 类样本, 6146 样本) 基础上**增量**加入 neg 辅助
token 变体, 观测: ①总体 acc 是否保持 (增量不破坏 OOD 泛化) ②辅助 token
同义/不同义/搭配的执行结果。

## 结果

| 配置 | 样本 | acc | valid | Δ (vs base) |
|---|---|---|---|---|
| base (复现 fold_num_v5) | 6146 | 0.9932 | 1.0000 | — |
| +1 同义辅助 (定义=neg) | 6156 | 0.9940 | 1.0000 | +0.0008 |
| +2 同义辅助 | 6156 | 0.9939 | 1.0000 | +0.0007 |
| +1 不同义辅助 (identity) | 6156 | 0.9941 | 1.0000 | +0.0010 |
| +同义+不同义 (搭配) | 6156 | 0.9941 | 1.0000 | +0.0010 |

## 结论

1. **基线复现成功**: fold_num_v5 acc 0.9932 (归档 0.9938, 同 seed 误差内),
   valid 1.0000 — OOD 无损泛化保持
2. **增量不破坏**: 全部辅助 token 配置保持 OOD 泛化 (valid 全 1.0000),
   总体 acc 微幅改善 (+0.0007 ~ +0.0010)
3. **同义/不同义/搭配无显著差别**: 四种变体 Δ 均在 ±0.001 内 —
   辅助 token 的语义 (同义/不同义) 对总体执行结果无区分度
4. neg 专项样本仅 +10 (基线 6146 中淹没), neg 专项效果需更大样本量
   才能观测 (后续: 增加 neg+aux 样本占比)
