# 修正: 复平面基点 = i; Church 自然数迭代错误的证明

日期: 2026-08-14

## 1. 修正: 复平面基点是 i, 不是 0

**修正**: 复平面的基点是虚数单位 i (0+1i), 不是原点 0。
- i = 虚轴单位 (0+1i): 周期结构 (i⁴=1) 的生成元
- 基点 = 复数 i: 复平面结构的锚定点
- 之前实验 (cplx_basepoint) 用 cplx(0,1) 即 i 的复数对表示 — 底数正确,
  但"基点=原点"的表述错误, 修正为**基点 = i**

## 2. Church 自然数迭代错误: 证明

### 2.1 命题

**Church 的自然数迭代是错误的** — 它用自然数 (迭代次数) 定义自然数,
构成循环论证, 不能作为自然数的定义。

### 2.2 证明 (λ 演算结构分析)

Church numeral: n̄ = λf.λb. fⁿ(b), 隐含三个独立成分:
| 成分 | 角色 | 来源 |
|---|---|---|
| b (base) | 迭代起点 | 参数 |
| f (step) | 迭代步进 | 参数 |
| **n (count)** | **迭代次数** | **???** |

关键: **迭代次数 n 不是 base/step 的副产品**:
- fⁿ(b) 中, n 编码为"f 应用 n 次" — 这是**计数**
- 计数 = 自然数概念 (第 n 次)
- 用计数 (自然数) 定义自然数 = **循环论证**

### 2.3 形式化支撑

- mathlib/Pat 全部 iterate 定理以 Nat 为参数 (索引确认):
  `mul_eq_sum_iterate (a) (n : ℕ)`, `conj_preserves_iterate (x n : ℝ)` —
  迭代次数统一由 ℕ 提供
- Church numeral 类型 (α→α)→α→α: 组合行为 (n̄∘m̄ = (n·m)̄) 的证明
  需要计数 (n·m = n 次加 m) — 计数预设 Nat
- 无 Nat 系统中无法区分 n̄ 与 m̄ 的"第几次" — 迭代次数不可由
  base/step 单独导出

### 2.4 结论

**Church 编码不能定义自然数** (循环: 用计数定义计数)。
自然数的正确来源: 迭代结构的生成必须先于自然数
(迭代 → 基点/方向选择 → 结构 → 自然数作为表示定理的结论)。

## 3. 对实验的前提意义

复平面基点 (i) 的显性化实验, 迭代结构不能用 Church 编码
(不能以 n 为 primitive) — 单次迭代 (z ↦ z·i) 而非 z^n 计数,
与 λ 迭代结构纪律一致。
