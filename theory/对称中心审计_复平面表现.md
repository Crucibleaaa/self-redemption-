# 实验过程: 对称中心审计 + 复平面表现

日期: 2026-08-14 | 纯实证 (v5 求值器, 不讲理论)

## 1. 对称中心审计 (固定点, 一元算符全测)

| 算符 | 固定点 | 对称中心 |
|---|---|---|
| neg | {0} | 原点 0 |
| inversion | {1} | 1 |
| reciprocal | {±1} | ±1 |
| imaginary | {-1} | -1 (求值器常数化, 见下) |
| translation | 无 | 无 |
| succ | 无 | 无 |

**观测**: 对称中心不同在已测 6 个算符中普遍存在 —
三类 (0 / ±1 / 无)。不是 inversion 特有, 是普遍现象。

## 2. 复平面表现

- imaginary(2) = -1: v5 求值器 (整数域) 把 imaginary 常数化 (i² 语义
  或实现简化), 无真正复数运算
- 复平面上的对称性 (旋转/周期) 无法在 v5 求值器中表现:
  求值域为整数, 无虚部

**观测**: 当前 tokenizer 无法观测复平面上的对称性表现 —
imaginary 仅作为标记 token 存在, 求值退化为常数。

## 3. 实验结论 (过程记录)

1. 对称中心不同 (0/±1/无) 在多元算符中普遍存在 — 非单例
2. 复平面表现无法在当前求值器观测 (整数域限制)
3. 后续实验方向: 扩展求值器支持虚数运算 (或复数对),
   观测对称性在复平面上的中心/周期行为
