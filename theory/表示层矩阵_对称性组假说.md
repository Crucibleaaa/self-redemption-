## 补强 7: 对称性组假说

**命题**: 模型认知的正确反演结构, 可能同时存在**一组额外的对称性**
才能准确定义结构; 或者模型认知的平移, 存在一组对称性。

**反演 (reciprocal) 的正确结构 = 对称性组**:
| 对称性 | 内容 | 标准定义 (D:153) |
|---|---|---|
| 对合 | recip(recip x) = x | ✓ 有 |
| 固定点 | recip(1) = 1 | ✓ 有 |
| **乘法自同构** | recip(x·y) = recip(x)·recip(y) | **✗ 缺** |
| **逆方向** | recip 与乘法逆关联 (recip(a) = division(1,a)) | **✗ 缺** (inversion 定义链还错为 -1/a) |

**论证**: 标准 reciprocal 定义链只有对合 + 固定点, 缺乘法自同构与
除法关联 — 定义不完整 (缺对称性组) → 模型只能部分归纳 → 0.997 残差。
直觉算符 (iop) 训练时隐含学习完整对称性组 → 1.000 完美。

**平移 (translation) 同理**: 正确平移结构需要方向对称性组
(成对方向 d,-d, R136) — 单方向定义不完整。

**统一理论**: 结构定义正确 = 定义链包含该算符的**完整对称性组**;
缺任何一条对称性 = 结构不完整 = OOD 不完美 (残差 = 缺的对称性的
指纹)。完美 OOD (1.000) ⟺ 对称性组完整。

## 验证方向 (可证伪)

补全 reciprocal 定义链 (加乘法自同构规则 + division 关联)
→ 结构算符应恢复 1.000 (若对称性组假说成立)。
