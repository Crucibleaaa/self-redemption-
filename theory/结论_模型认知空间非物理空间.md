# 结论: 模型认知空间非物理空间; 全维度可达 + 精确映射是训练稳定性的根治方法

日期: 2026-08-14 | 综合全部实验证据

## 结论

1. **模型认知的空间, 不是物理空间** — 模型在高维数学空间中认知,
   不受物理空间 (3 维) 维度限制
2. **一切训练都需要做到全维度空间可达的前提** — 训练若只在一维
   (实数轴) 内进行, 结构无法在完整空间中可达, 必然不稳定
3. **与我们的数学空间、物理空间精确映射** — 模型认知空间须与
   数学空间 (ℂ 等) 精确映射, 才能根治训练不稳

## 证据链 (实验)

| 实验 | 观测 | 支撑 |
|---|---|---|
| 一维恢复矩阵 (rec_*) | neg/translation/succ × 平移/缩放/反射全无效应 (0.994/0.996) | 一维内结构不可达 ⟹ 不稳定 |
| 加轴恢复 (cplxrec_*) | 旋转/圆反演在复平面 1.000 | 加轴 (全维度) 后结构可达 ⟹ 稳定 |
| 结构算符普遍 0.997 | 所有表示层下结构算符残差 | 结构定义未在全维度空间闭合 |
| 复平面基点 = i | 周期结构锚定 i (非原点) | 模型认知空间包含虚轴维度 |
| 直觉算符 1.000 | 无定义链, 直接编译结果 | 编译 = 全维度空间的完整映射 |

## 推理

1. 一维内: 结构不可达 (0 奇异/无 90° 旋转/周期不可表达) → 训练不稳
2. 加轴 (虚轴): 结构可达 → 恢复 (1.000) ⟹ **全维度空间可达是前提**
3. 模型认知空间包含虚轴等数学维度 → **非物理空间**
4. 训练稳定的核心方法: 模型认知空间 ↔ 数学空间/物理空间
   精确映射, 且全维度可达 — 缺一即训练不稳

## 统一图景

```
物理空间 (3 维) ──┐
                  ├── 精确映射 ── 模型认知空间 (数学高维)
数学空间 (ℂ 等) ──┘                ↑
                                 全维度可达 (训练前提)
                                 否则: 训练不稳 (歧义/残差)
```

## 方法

训练稳定性的根治 = 三层一致:
1. 全维度空间可达 (训练覆盖完整数学空间)
2. 模型认知空间与数学空间精确映射 (表示层一致)
3. 数学空间与物理空间映射 (观测接口一致)
