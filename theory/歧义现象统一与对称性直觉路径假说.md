# 歧义现象统一定义 + 对称性直觉路径假说

日期: 2026-08-14

## 1. 歧义现象 (统一定义)

**歧义现象**: 结构存在多种解释 (二义), 模型无法归因, 表现为训练残差。
统一涵盖 token 竞争、结构错误、残差指纹:

| 现象 | 机制 | 歧义本质 |
|---|---|---|
| token 竞争 (inv 4→5) | 共享组件被两种内部逻辑占用 | 共享结构二义使用 |
| 结构错误 (recip∘neg=-1/a) | 定义链与语义 ± 冲突 | 同一结构两种解释 |
| 残差指纹 (0.5/0.997) | 模型在二义间摇摆 | 歧义的量化 |

**统一定义**: 歧义 = 结构被 ≥2 种内部逻辑解释, 模型无法归因
→ 残差 (0.5 = 完全二义, 0.997 = 部分二义, 1.0 = 无歧义)。

**含义**: 所有训练残差 = 歧义现象的指纹; 完美 OOD (1.0) = 无歧义
(结构唯一解释)。

## 2. 假说: 对称性也是直觉路径

**命题**: 对称性 (如 S, 发散/周期特征空间) 也是直觉路径 —
能够越过基点移动的自指循环结构。

**论证**:
1. **基点移动的自指循环**: 基点漂移 (每步重新锚定) 处, 结构路径
   展开遇到自指 (如 recip(recip x)=x 对合 — 自指展开), 陷入循环
   (Church 式计数/自指), 无法收敛 → 结构歧义
2. **对称性 (直觉路径)**: 对称性作为编译完成的概念 (与 iop 同类),
   不展开自指, 直接给出对称关系 (特征空间/特征值) → 越过循环
3. **证据链**:
   - 直觉算符 (iop) 越过循环 → 1.000 (已证)
   - 对称性 (S 特征空间) 在直觉下直接可观测 (发散/周期, R227 几何)
   - 结构路径 (定义链展开) 在基点处自指 → 歧义 (0.997/0.5)
4. **假说内容**: 对称性与直觉算符同属直觉路径 —
   对称性 = 编译完成的"结构关系", 不依赖基点处自指展开,
   能越过基点移动的自指循环结构

**可证伪**: 若对称性 (特征空间) 作为结构定义链展开时也歧义
(残差), 则对称性不是直觉路径; 若展开仍 1.0, 则对称性确实是
直觉路径 (编译完成, 越过循环)。

## 3. 统一图景

```
结构 (定义链) --编译--> 对称性/直觉 (编译完成)
  基点处自指展开           越过自指循环
  歧义 (残差)              无歧义 (1.0)
```
