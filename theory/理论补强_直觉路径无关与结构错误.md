# 理论补强: 直觉与路径无关; 结构错误是结构算符消化不好的原因

> 2026-08-14 | 基于 EXP-DUAL-PATH 2×2 消融 + 定义链审计

## 补强 1: 直觉与路径无关

**命题**: 直觉符号 (无方程原子, 如 iop) 的学习不依赖载体路径 —
numeral 直觉/结构、算符上下文均不影响其收敛。

实验证据 (EXP-DUAL-PATH):
| 配置 | 算符 | numeral | 判定 | 未达标 |
|---|---|---|---|---|
| 1 | 结构 | 结构 | 0.997 | 1/31 (inversion 0.5) |
| 2 | 结构 | 直觉 | 0.997 | 1/31 (inversion 0.5) |
| 3 | **直觉** | 结构 | **1.000** | 0/31 |
| 4 | **直觉** | 直觉 | **1.000** | 0/31 |

- 直觉算符在两种 numeral 路径下都 1.000 (路径无关)
- 结构算符在两种 numeral 路径下都 0.997 (路径无关)
- 差异完全由算符表示决定, 与 numeral 载体路径无关

**含义**: 直觉 = 自足概念 (编译完成, 不依赖结构上下文); 路径
(numeral 表示) 只影响推理 token 数/速度, 不影响收敛质量。

## 补强 2: 结构错误是结构算符消化不好的原因

**命题**: 结构算符 (定义链展开) 消化不好 ⟺ 定义链结构与语义冲突
(结构错误), 非"结构路径本身慢"。

**定义链审计** (标准 inversion D:164 / reciprocal D:153):
```
inversion 规则1: inversion(a) = reciprocal(neg(a))   [D:164]
                = 1/(-a) = -1/a   ≠ 语义 1/a        ← 结构错误!
reciprocal 规则: 对合 + 固定点 1                      [D:153]
                无 "reciprocal(a) = division(1,a)" 规则 ← 缺分数语义
```

**冲突**: 引擎按 1/a 求值 (样本真值), 定义链规则给出 -1/a —
模型在两种语义间摇摆 → 判定残差 **0.5** (± 符号随机) → 0.997。

**结论**: 结构算符消化不好 = 定义链结构错误 (与表示层冲突),
不是"结构路径慢"。残差 0.5 恰好对应 ± 符号冲突 (半对半错)。

## 验证方向 (纯实证, 可证伪)

修正 inversion 定义链 (规则改为与语义一致: inversion(a) =
reciprocal(a), 且 reciprocal(a) = division(1, a) 补分数规则)
→ 结构算符应恢复 1.000 / 无残差。对比修正前后即验证。

## 补强 3: 统一假说 — 训练失败 = 结构错误 (定义链与表示层冲突)

**命题**: 本项目全部"学不会"案例可统一归因于结构错误 (定义链与表示层
冲突), 非模型/数据/样本问题。

| 案例 | 结构错误 | 残差 |
|---|---|---|
| inversion 标准 | 定义链 -1/a vs 引擎 1/a (± 冲突) | 0.5 |
| neg 单独 | 低多样性 (混合可恢复 — 非结构错误, 多样性缺失) | 0.054 |
| succ/translation 自定义样本 | 合成错误 (非官方格式) | 0.000 |
| inversion iop | 无定义链 (直觉自足) | 1.0 |

**分类**:
- 结构错误 (定义链与语义冲突) → 残差 0.5 级 (二义)
- 表示层不可表示 (分数) → 样本缺失 → 无法学习 (0.000)
- 合成格式错误 (非官方) → 0.000
- 直觉符号 (无定义链) → 1.0 (无错误可犯)

## 补强 4: 残差指纹 = 结构错误类型映射

| 残差模式 | 错误类型 | 机制 |
|---|---|---|
| **0.5** | 二义语义冲突 (± 摇摆) | 定义链与引擎两种语义, 模型随机选择 |
| **0.0** | 结构不可表示 / 无样本 | 表示层无法承载该结构 |
| **0.05 级** | 部分冲突 / 多样性不足 | 少量样本覆盖, 多数未归纳 |
| **1.0** | 无冲突 (直觉自足) | 无定义链, 无错误可犯 |

**含义**: 训练残差不是随机噪声, 是**结构错误的指纹** — 由残差模式
可反推错误类型 (二义/不可表示/缺失)。

## 补强 5: 直觉符号 = 编译完成, 与表示层解耦

**命题**: 直觉符号 (无方程原子) = P0 的"直觉 = 完成了编译的构造" —
编译完成后与定义链/表示层解耦:

1. 编译完成 (权重已固化语义) → 不依赖定义链 → 结构错误免疫 (1.0)
2. 与表示层解耦 → 路径无关 (numeral 直觉/结构无差别) →
   推理 token 数/速度只由载体决定
3. 代价: 直觉符号无法检查 (无定义链可追溯) — 正确性依赖编译期
   (训练时), 需验证器 (P2 fallback)

**三层模型**:
```
结构符号 (定义链)  --编译-->  直觉符号 (原子)  --表示-->  推理 (载体决定 token 数)
   可追溯/可检查                不可检查 (需验证器)          路径无关
   结构错误敏感                    结构错误免疫
```

## 补强 6: 完美 OOD 是正确性判据; 结构定义错误假说

**命题 1 (正确性判据)**: 只有完美 OOD (判定 1.000 / 0 残差) 才能证明
结构正确; OOD 不完美 (有残差) 即说明错误。

- 完美 OOD = 结构在训练外 (位宽/表示) 一致闭合 ⟹ 正确
- 不完美 OOD (残差) = 结构内部矛盾 (定义链与语义冲突) ⟹ 错误

**命题 2 (结构定义错误, 表示层无辜)**: 同一表示层下, 直觉算符完美
(1.0) 而结构算符不完美 (0.997/残差 0.5) ⟹ 差异在结构定义 (定义链),
表示层没有错:

```
同一表示层 (负指数幂)
├── 直觉算符 (iop, 无定义链): 完美 OOD (1.000)  ← 表示层没问题
└── 结构算符 (标准, 有定义链): 不完美 (0.997)   ← 定义链错误
        ⟹ 错误在结构定义, 表示层无辜
```

**命题 3 (表示层对比实验)**: 需要在多个表示层下测试结构算符,
看结构算符是否普遍不完美:
- 若所有表示层下结构算符都不完美 ⟹ 结构定义普遍错误 (表示层无关)
- 若某表示层下结构算符完美 ⟹ 表示层影响 (该层与结构定义兼容)

**实验设计**: 表示层 (power/div/mulrecip) × 算符 (结构/直觉) 矩阵,
观测结构算符是否普遍不完美 (0.997/残差) vs 直觉算符普遍完美 (1.000)。
