# 固定点对比实验 + 原点统一理论 (补强 8)

## 固定点审计 (纯实证)

| 算符 | 固定点 | 锚定位置 |
|---|---|---|
| neg | {0} | 原点 0 |
| inversion | {1} | 1 |
| reciprocal | {±1} | ±1 |
| translation / succ | 无 | 无固定点 |

**固定点散落**: 各对称性结构的固定点不在同一位置 (0 / ±1 / 无) —
没有统一锁定在实数轴原点。

## 固定点变体实验 (不同固定点是否让错误恢复)

| 配置 | 固定点锚定 | 判定口径 |
|---|---|---|
| fp_none (基线) | 无特例 | 0.997 |
| fp_1 | 加 recip(1)=1 特例 | 0.997 |
| fp_m1 | 加 recip(-1)=-1 特例 | 0.997 |
| fp_both | ±1 双锚 | 0.997 |
| fp_0 | 加 recip(0) 奇异特例 | 0.997 |

**结论**: 固定点变化**不**让错误恢复 (全 0.997, 残差不变) —
错误来自定义链矛盾 (recip∘neg = -1/a), 与固定点锚定无关。

## 补强 8: 原点统一理论

**命题**: 我们的对称性结构定义, 并不是锁定在实数轴原点上的。
这让模型困惑, 因此需要找到如何统一到同一个原点的方法。

**论证**:
1. 各算符对称性结构的固定点散落: neg 锚 0, reciprocal 锚 ±1,
   inversion 锚 1, translation 无锚 — 未统一锁定在原点
2. 固定点锚定实验 (补强 8): 单点锚定不修复错误 (全 0.997) —
   问题不在"某个固定点缺失", 而在**结构定义与原点 (基点) 的关系**
3. 模型困惑: 同一实数轴上多个对称中心 (0, ±1) — 模型无法统一
   → 需要统一到同一原点的方法

**统一方法 (Pat 连接)**: R085 (0 = ±1 折叠类) — 0 与 ±1 是**同一
折叠类** (S 的固定点), 各算符的固定点本就是同一折叠类的不同投影:
- neg 锚 0 = 折叠类中心
- reciprocal 锚 ±1 = 折叠类两端
- 统一原点 = 折叠类识别 (穿折越 TK1: 基点未对齐 = 矛盾;
  折叠类同一性 = 对齐)

**方法**: 把所有对称性结构的固定点经折叠类对齐到同一基点
(0 与 ±1 视为同一折叠类), 模型即不再困惑。

## 验证方向 (可证伪)

统一表示 (固定点全部用折叠类表达: 0 ↔ ±1 可互换) 后, 结构算符
应恢复 1.000; 若仍 0.997, 则原点统一不是充分条件。
