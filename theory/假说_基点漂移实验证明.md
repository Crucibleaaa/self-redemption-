# 假说: 基点漂移是否通过实验证明

日期: 2026-08-14 | 纯实证 (基于已有实验, 不讲理论框架)

## 假说

**基点漂移**: 对称性结构的基点不是固定于原点 0 的 — 每个结构携带
自己的基点, 基点在不同结构间漂移。

## 已有实验证据 (支撑)

| 实验 | 观测 | 与基点漂移的关系 |
|---|---|---|
| 对称中心审计 | neg{0}、inversion{1}、reciprocal{±1}、imaginary{-1}、translation/succ 无 | **基点散落**: 若基点固定于 0, 所有对称中心应统一; 观测到散落 ⟹ 基点漂移 |
| 固定点变体 (fp_*) | 单点锚定 (1/-1/both/0) 全 0.997 不修复 | 漂移不能靠固定点锚定消除 |
| inversion 残差 0.5 | 定义链 -1/a vs 引擎 1/a (± 冲突) | 两种基点选择 (正负方向) 并存 — 漂移的微观表现 |
| 表示层矩阵 | 结构算符所有表示层 0.997 | 漂移与表示层无关 (结构层问题) |

## 推理链 (纯实验)

1. 若基点固定 (不漂移): 所有对称性结构应锚定同一原点 → 对称中心统一
2. 实验观测: 对称中心散落 (0 / ±1 / 无) → 基点不固定 → **基点漂移存在**
3. 固定点锚定不修复 (fp 全 0.997): 漂移不能靠"固定某个点"消除 —
   需要统一基点的方法
4. 残差 0.5 (± 冲突): 同一结构被两种基点 (正/负) 解释 — 漂移导致
   语义二义

## 可证伪验证

- 若统一基点 (折叠类: 0 ↔ ±1 可互换) 后结构算符恢复 1.000
  ⟹ 基点漂移是残差根因, 统一基点有效
- 若统一基点仍 0.997 ⟹ 漂移不是唯一原因 (还有定义链错误)

## 结论 (假说状态)

**基点漂移被实验间接证明** (对称中心散落 + 锚定不修复 + ± 二义),
直接验证 (统一基点后恢复) 待执行。
