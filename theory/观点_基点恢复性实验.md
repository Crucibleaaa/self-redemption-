# 观点: 基点恢复性实验 (数值相等但位置不同 → 基点归一化恢复)

日期: 2026-08-14

## 观点

数值确实相等, 但因基点位置不同导致的实际位置不同 — 这是歧义来源。
恢复性实验: 将基点恢复为 0 (归一化), 数值减基点偏移, 是否得到准确结果?

例: 训练乘法时, 将基点恢复为 0, 将数值减 1 —
乘法结构基点 (乘法单位 1) 恢复为原点 0, 数值减 1 (坐标平移)。

## 恒等式先验 (基点 1 → 0 的乘法平移)

✅ (x-1)·(y-1) + (x-1) + (y-1) + 1 = x·y (Z/13 无反例)
— 以 1 为基点的乘法可经平移表达为 0 基点; 数值减 1 是坐标变换,
基点恢复 0 后同一数值的"位置"唯一。

## 恢复性实验设计

- 对照: 标准乘法判定 (基点隐含)
- 恢复: 乘法判定用基点归一化表达 — 数值减 1 (0 基点坐标)
  [mul][x-1][y-1] = (x-1)·(y-1)
- 检验: 恢复表达是否准确 (若基点漂移是歧义源, 归一化后应无歧义)
