# 观点: 直觉可用 ≠ 结构正确; 训练结果是结构错误的实证探测器

日期: 2026-08-14 | 纯实证 (基于全部实验证据)

## 观点 1: 直觉认知可用不代表结构正确

**命题**: 直觉算符 (iop) 训练完美 (1.000) 不代表其对应结构定义正确;
大模型的训练结果 (残差) 可指导对结构错误的实证研究。

**证据链**:
1. 直觉算符 (iop, 无定义链): 所有配置 1.000 完美 — 直觉认知可用
2. 但标准结构定义 (reciprocal/inversion): 定义链审计发现错误
   (recip∘neg = -1/a ≠ 1/a; 缺乘法自同构/除法关联)
3. 模型训练残差精确指示错误位置: inversion 0.5 (± 二义)、
   结构算符 0.997 — 残差 = 结构错误的指纹
4. 直觉完美与结构错误并存 ⟹ 直觉可用不能证明结构正确

**结论**: 大模型训练 = **结构正确性的实证探测器**:
- 训练残差 → 定位结构定义错误 (残差指纹: 0.5=二义, 0.0=不可表示)
- 直觉完美 ≠ 结构正确 (直觉是编译结果, 不承载结构可追溯性)

## 观点 2: 基点漂移 ⟹ 加法后继数值相等但位置不同

**命题**: 如果基点存在漂移, 意味着加法的后继结果数值相等,
但在实数轴上的位置不同。

**推理** (纯实证):
1. 固定点审计: neg 锚 0, reciprocal 锚 ±1, inversion 锚 1 —
   同一实数轴上, 各结构锚定位置不同 (基点漂移)
2. 若基点漂移: 后继 n → n+1 的"数值" (n+1) 在所有基点下相同
   (数值不变), 但"位置" (相对各基点的坐标) 不同
3. 例: 数值 2 — 以 0 为基点位置 = +2; 以 1 为基点位置 = +1;
   以 -1 为基点位置 = +3 — **数值相等, 位置不同**
4. 固定点锚定实验 (fp_*): 锚定任意点都不修复 (0.997) —
   位置不确定无法靠单点固定

**结论**: 基点漂移 ⟹ 数值 (身份) 与位置 (坐标) 分离 —
同一数值在漂移基点上位置不同; 模型困惑来源 = 数值/位置未分离
(训练只给数值, 不给位置 — 位置不确定性 → 残差)。

## 可证伪验证

1. 若训练样本同时给出数值与位置 (如 基点=2 的坐标), 结构算符恢复
   1.000 ⟹ 数值/位置分离是正确方法
2. 若仍 0.997 ⟹ 分离不是充分条件
